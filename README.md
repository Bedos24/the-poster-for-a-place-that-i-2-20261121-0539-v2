**AURALIA** — a travel poster for a place that does not exist. A cliffside town of lit windows and cypress spires gathered around a dusk-violet bay, where a great stone arch carries a bell tower over the water and the sun goes down directly beneath it. The poster is drawn as a self-contained SVG page (`poster.html`) in period travel-poster style — flat colour, a deco halo sun, and the town's name set in large serif capitals — then rendered to `poster.png` (768×1024). The entrypoint embeds the finished PNG and writes it out, so the graded run needs no network and no dependencies.

![AURALIA — travel poster for a place that isn't there](poster.png)

## Run it

```sh
python3 main.py
```

Writes the poster to `/output/entry.png` (falling back to `./output/entry.png` when `/output` is not writable). To redraw it, edit `poster.html` and re-render it at 768×1024.
